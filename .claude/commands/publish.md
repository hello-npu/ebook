---
description: 변경분을 커밋하고 main에 push (위키독스 자동 발행)
---

전자책을 발행합니다. `main`에 push하면 위키독스가 자동 동기화합니다.

순서:
1. `git status`로 변경된 페이지를 확인하고, **무엇이 발행되는지 먼저 요약**해 보여줍니다.
2. 새/이동된 페이지가 있으면 `TOC.md`가 최신인지 확인합니다(아니면 `/toc` 먼저).
3. Conventional Commits 형식으로 커밋합니다. 예: `docs: 09장 서빙 개선 결과 추가`
4. `main`에 push합니다.

push 전, 사실 확인이 안 된 `📝 실습 채움` 자리가 그대로 발행돼도 괜찮은지 한 번 짚어 줍니다.
