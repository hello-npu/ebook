# 05. 모델 컴파일과 최적화

> 담당(오너): ⬜  ·  관련 세미나 주차: W3, W6  ·  상태: 골격 (실습 채움 필요)

## 개요

모델을 NPU에서 더 빠르고 효율적으로 돌리기 위한 컴파일 옵션과 최적화 기법(특히 양자화)을 다룹니다.

## 배경 / 이론

### 컴파일러가 하는 일

컴파일러는 모델 그래프를 NPU가 실행할 수 있는 형태로 변환하며, 이 과정에서 연산 융합·메모리 배치·정밀도 변환 같은 최적화를 적용합니다.

### 양자화

양자화는 가중치·활성값을 낮은 정밀도(예: FP16 → INT8)로 표현해 메모리와 연산을 줄이는 기법입니다. 속도·메모리 이득이 크지만 정확도 손실이 따를 수 있어, 둘의 균형을 확인하는 것이 중요합니다.
