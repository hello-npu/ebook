description: 발표자료/메모를 받아 챕터 초안을 pages/에 생성
argument-hint: <발표자료 경로 또는 주제 메모>
---

다음 입력을 바탕으로 전자책 챕터 초안을 작성합니다: $ARGUMENTS

규칙:
- `AGENTS.md`와 `templates/chapter.md`를 먼저 읽고 그 형식·규약을 따릅니다.
- 한국어 합니다체. 용어는 `pages/12-glossary.md`(용어집) 기준으로 표기합니다.
- 구조: 개요 / 배경·이론 / 실습 / 결과 / 막힌 점 / 참고.
- 사실 확인이 필요한 SDK 명령·수치·벤치마크는 **지어내지 말고** `> 📝 실습 채움` 자리표시로 남깁니다.
- 파일명은 `pages/NN-slug.md`(두 자리 번호, kebab-case), H1은 `# NN. 제목`으로 파일 번호와 일치시킵니다.
- 새 페이지를 만들면 `TOC.md`의 올바른 위치에 항목을 추가합니다(제목은 H1과 정확히 일치).

작성 후 어떤 부분이 초안이고 어디가 실습 채움 자리인지 요약해 알려줍니다.
