# 07. 생명과학 모델 도전기

> 담당(오너): ⬜  ·  관련 세미나 주차: W8, W9  ·  상태: 골격 (실습 채움 필요)

## 개요

단백질 언어 모델 등 생명과학 도메인 모델을 NPU에 올려보는 탐색 기록입니다. 무게·연산 특성상 포팅이 어려울 수 있어, 되는 것과 안 되는 것의 경계를 정직하게 기록하는 것이 목표입니다.

## 배경 / 이론

> 📝 실습 채움: 다루는 도메인 모델 소개(예: ESM-2)와 활용 시나리오.

## 실습

### 모델 구동 시도

> 📝 실습 채움: 모델 준비·컴파일 시도, 지원 여부 확인.

## 결과

> 📝 실습 채움: 구동 성공/실패, 성능 또는 막힌 지점.

## 막힌 점 / 해결

> 📝 실습 채움: 포팅 난점, 대안 모델로의 전환 여부.
