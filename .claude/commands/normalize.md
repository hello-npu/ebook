대상: $ARGUMENTS (비어 있으면 `pages/` 전체)

`AGENTS.md` 규약과 `pages/14-glossary.md` 용어집을 기준으로 다음을 점검·수정합니다.

- 용어 표기 통일 (용어집과 다른 표기를 맞춤, 처음 등장 시 영문 병기)
- 한국어 합니다체로 문체 통일
- H1은 한 개, 제목 단계 건너뜀 없음, H1 번호와 파일 번호 일치
- 본문 목록은 `-`, 코드블록에 언어 명시
- 페이지 간 링크는 `pages/` 내 상대경로로 올바른지 확인
- 깨진 링크·이미지 경로 점검

내용(사실·수치)은 바꾸지 않습니다. 표기·형식만 손봅니다. 변경 사항을 요약해 보고합니다.
