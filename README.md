# 리벨리온 NPU 실전 가이드

리벨리온(Rebellions) 서버용 NPU에 실제 AI 모델을 올려 보며 정리한 한국어 실전 가이드입니다. 교과서처럼 개념만 설명하지 않고, 직접 컴파일하고 돌려 보고 막히고 해결한 기록을 함께 담습니다. 직접 잰 수치에는 측정 환경과 조건을 같이 적고, 외부 수치에는 출처를 답니다.

## 누구를 위한 책인가

- GPU로 모델을 돌려 본 적은 있지만 NPU는 처음인 개발자와 연구자
- NPU가 GPU와 무엇이 다르고, 어떤 워크로드에 맞는지 판단하고 싶은 분
- 리벨리온 NPU(ATOM)와 RBLN SDK로 모델을 컴파일하고 서빙해 보려는 분

## 구성

**1부 NPU 기초**에서는 NPU가 무엇을 버리고 무엇을 얻었는지에서 출발해, 하드웨어 구조와 그 하드웨어를 잘 쓰는 소프트웨어 기법을 다룹니다.

- 01. NPU Intro: 무엇을 버리고, 무엇을 얻었는가?
- 02. NPU HW Architecture: AI 추론을 위한 전용 하드웨어
- 03. Model Optimization: NPU 100% 활용하기
- 04. Low Precision & Quantization: 성능과 효율 사이
- 05. RBLN SDK 시작하기: Hello, NPU!

**2부 AI 모델**에서는 실제 모델을 NPU에 올려 정확도·속도·전력을 재고, LLM 서빙의 기반이 되는 vLLM을 살펴봅니다.

- 07. NLP 모델 구동기 및 벤치마크 성능 비교
- 08. LLM과 vLLM 이해하기

NPU에서의 LLM 서빙과 개선 사례(3부), 벤치마크 모음·자주 막히는 것들·용어집(부록)은 계속 채워 나가고 있습니다.

## Hello, NPU 랩

Hello, NPU는 리벨리온 NPU 서버를 함께 쓰며 매주 세미나로 공부하고 실험하는 스터디 랩입니다. 이 책은 랩원들이 세미나에서 발표하고 실습한 내용을 장별로 정리한 것이며, 완성본보다 꾸준히 자라는 기록을 목표로 합니다.

원고와 기여 방법은 [GitHub 저장소](https://github.com/hello-npu/ebook)의 `CONTRIBUTING.md`에 있습니다.
